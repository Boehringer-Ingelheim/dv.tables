# dv.tables

This package contains the following modules:

- [Hierarchical Event Count module](https://boehringer-ingelheim.github.io/dv.tables/articles/hierarchical_count_table.html)
- [Summary table module](https://boehringer-ingelheim.github.io/dv.tables/articles/summary_table.html)
- [Tplyr table module](https://boehringer-ingelheim.github.io/dv.tables/articles/Tplyr_tables.html)

# Installation

``` r
if (!require("remotes")) install.packages("remotes")
remotes::install_github("Boehringer-Ingelheim/dv.tables")
```
