# Create user interface for the export count table shiny module of dv.tables

Create user interface for the export count table shiny module of
dv.tables

## Usage

``` r
mod_export_counttable_UI(module_id)
```

## Arguments

- module_id:

  `[character(1)]` A unique ID string to create a namespace. Must match
  the ID of
  [`mod_export_counttable_server()`](mod_export_counttable_server.md).

## Value

A shiny `uiOutput` element.

## Functions

- `mod_export_counttable_UI()`: This function creates the user interface
  for the export count table shiny module.
